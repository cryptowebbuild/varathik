# ভাড়াঠিক? (VaraThik)

**ঠকবেন না, জেনে উঠুন।**

ঢাকায় বাস, মেট্রোরেল, CNG অটোরিকশা আর রিকশার **সরকার নির্ধারিত / ন্যায্য ভাড়া** এক ট্যাপে যাচাই করার ওয়েব অ্যাপ (PWA)। বেশি ভাড়া চাইলে কন্ডাক্টর/ড্রাইভারকে দেখানোর জন্য **শেয়ারযোগ্য অফিসিয়াল ভাড়া কার্ড** তৈরি হয়।

[Arohon — Build for Bangladesh](https://arohon.co/challenges/build-for-bangladesh) চ্যালেঞ্জের এন্ট্রি।

**লাইভ ডেমো: https://cryptowebbuild.github.io/varathik/**

## কী কী আছে

- **From → To ভাড়া তুলনা** — বাস, মেট্রো, CNG (মিটার), রিকশা পাশাপাশি: ভাড়া, দূরত্ব, আনুমানিক সময়; সবচেয়ে সস্তা অপশন হাইলাইট
- **সরাসরি বাস রুট** — প্রধান করিডরগুলোতে কোন বাস, কোন কোন স্টপ হয়ে যাবে, স্টপ অনুযায়ী ভাড়া
- **"বেশি নিয়েছে?" যাচাই** — কত টাকা নিয়েছে লিখলেই সরকারি ভাড়ার সাথে তুলনা করে রায়
- **ভাড়া কার্ড** — Canvas দিয়ে তৈরি PNG কার্ড (রুট, সরকারি ভাড়া, সূত্রসহ), Web Share API / ডাউনলোড
- **সরকারি রেট পেজ** — সব রেটের সূত্র ও কার্যকরের তারিখ
- বাংলা-প্রথম UI, মোবাইল-ফার্স্ট, PWA (অফলাইন ক্যাশ, হোম স্ক্রিনে ইনস্টল)
- **৮৩টি এলাকা · ৩০টি বাস করিডর** — সাভার, টঙ্গী, ডেমরা, সদরঘাটসহ ঢাকার প্রায় সব প্রধান এলাকা
- **এক বদলির রুট** — সরাসরি বাস না থাকলে কোন স্টপে বদলালে সবচেয়ে কম ভাড়ায় পৌঁছাবেন
- **প্রিয় ও সাম্প্রতিক রুট** — নিজের ডিভাইসেই সংরক্ষিত (কোনো অ্যাকাউন্ট লাগে না)
- **WhatsApp শেয়ার** — ভাড়ার তথ্য এক ট্যাপে পাঠিয়ে দিন
- **ডার্ক মোড + English UI** — থিম ও ভাষা টগল
- **মেট্রোর সময়সূচি** — প্রথম/শেষ ট্রেন ও ট্রেনের ব্যবধান (DMTCL)
- **MRT/Rapid Pass ১০% ছাড়** — মেট্রো ভাড়ায় কার্ড-ছাড় টগল ও মাসিক সাশ্রয় হিসাব

## ভাড়ার সূত্র (অনুমান নয়)

| যান | রেট | সূত্র |
|---|---|---|
| সিটি বাস | ৳২.৭০/কিমি, সর্বনিম্ন ৳১০ (মিনিবাস ৳২.৬০/৳৮) | BRTA মহানগর ভাড়া চার্ট, কার্যকর ২২ সেপ্টেম্বর ২০২৬ |
| মেট্রোরেল MRT-6 | ৳৫/কিমি, সর্বনিম্ন ৳২০, সর্বোচ্চ ৳১০০ | DMTCL/DTCA অফিসিয়াল চার্ট |
| CNG (মিটার) | প্রথম ২ কিমি ৳৪০, এরপর ৳১২/কিমি, অপেক্ষা ৳২/মিনিট | BRTA মিটার রেট, সড়ক পরিবহন আইন ২০১৮ |
| আন্তঃজেলা বাস | ৳২.৪০/কিমি | BRTA আন্তঃজেলা চার্ট |
| রিকশা | সরকারি রেট নেই — বাজারভিত্তিক রেঞ্জ, পরিষ্কারভাবে "আনুমানিক" লেবেল | ফিল্ড সার্ভে |

সব রেট একটাই ফাইলে: `src/data/rates.ts` — সরকার রেট বদলালে শুধু ওই ফাইল আপডেট করলেই চলবে।

## গঠন

```
src/
  data/    rates.ts (সরকারি রেট) · places.ts (এলাকা) · metro.ts (স্টেশন/ভাড়া) · busRoutes.ts (করিডর)
  lib/     fare.ts (ভাড়া ইঞ্জিন) · fareCard.ts (শেয়ারযোগ্য কার্ড)
  App.tsx  UI (সার্চ, রেজাল্ট, যাচাই, রেট পেজ)
```

দূরত্ব: বাস রুটে স্টপ-ভিত্তিক সঞ্চিত দূরত্ব; অন্য যানে স্থানাঙ্ক থেকে সড়ক-দূরত্ব (সরলরেখা × ১.৩)।

## চালানো

```bash
npm install
npm run dev     # ডেভেলপমেন্ট
npm run build   # প্রোডাকশন বিল্ড (dist/)
```

## দাবিত্যাগ

ভাড়াঠিক কোনো সরকারি প্রতিষ্ঠান নয় এবং BRTA/DMTCL-এর সাথে সম্পৃক্ত নয়। ভাড়া প্রকাশিত সরকারি রেট থেকে হিসাব করা; কোনো কোনো অপারেটরের নিজস্ব চার্টে সামান্য পার্থক্য থাকতে পারে।
